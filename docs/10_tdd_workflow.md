# TDD-Oriented Workflow Demonstration

This portfolio adopts a **TDD-oriented** learning workflow rather than claiming production TDD experience.

1. Define the requirement and acceptance criteria.
2. Write a failing test that expresses the expected behavior.
3. Implement the smallest behavior needed to satisfy the test.
4. Refactor while keeping the regression suite green.
5. Preserve the test as executable documentation.

The final repository contains the executable tests and requirements traceability. Git history can be used to demonstrate the red → green → refactor progression if the project is committed incrementally on GitHub.
