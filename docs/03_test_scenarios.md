# Test Scenarios

## TS-01 — Case registration
Validate creation, mandatory fields, uniqueness and input boundaries.

## TS-02 — Case lifecycle
Validate status transitions and persistence.

## TS-03 — Authorization
Validate role-based permission boundaries and negative paths.

## TS-04 — Auditability
Validate that relevant changes create traceable audit records.

## TS-05 — End-to-end workflow
Validate register → update → retrieve → audit.

## TS-06 — Regression
Validate core registration remains available after workflow changes.

## TS-07 — Basic performance
Measure repeated API calls locally and identify obvious degradation; results are illustrative, not a formal capacity benchmark.
